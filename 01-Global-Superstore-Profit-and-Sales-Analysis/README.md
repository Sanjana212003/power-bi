# Global Superstore Profit and Sales Analysis

## Overview

This Power BI report analyzes sales and profit performance using the Global Superstore dataset. The dashboard focuses on product-level profitability and geographical sales distribution.

## Key Analysis

* Profit by Product Name
* Sales by Country
* Identification of high-profit products
* Geographical distribution of sales
* Overall Quantity, Sales, and Profit KPIs

## Dashboard Highlights

The report provides a visual overview of business performance through:

* Horizontal bar charts for product-level profit comparison
* Geographical map showing sales distribution by country
* KPI cards for total quantity, sales, and profit
