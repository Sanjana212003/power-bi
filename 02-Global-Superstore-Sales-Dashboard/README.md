## Overview

This Power BI dashboard provides an interactive analysis of sales performance across product categories, regions, countries, and time periods using the Global Superstore dataset.

## Key Analysis

* Sales by Category
* Sales by Region
* Sales distribution across countries
* Product and sub-category analysis
* Order date and sales analysis
* Year and region filtering

## Dashboard Highlights

The report includes interactive visualizations such as:

* Category-wise sales comparison
* Regional sales analysis
* Geographical sales map
* Product/category hierarchy
* Interactive year and region filters
* Total Sales KPI
