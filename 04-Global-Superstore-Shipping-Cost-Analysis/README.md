## Overview

This Power BI report analyzes shipping costs across different product categories using the Global Superstore dataset. The report focuses on comparing shipping expenses and identifying category-level differences.

## Key Analysis

* Shipping Cost by Category
* Comparison of Technology, Furniture, and Office Supplies
* Category-wise shipping cost distribution
* Shipping cost comparison using combined visualizations

## Dashboard Highlights

The report uses multiple visualizations to analyze shipping costs, including:

* Bar chart for category-wise shipping costs
* Donut chart showing shipping cost distribution
* Comparative chart for category-level shipping costs
* Category-based performance comparison

## Key Categories

The analysis covers:

* Technology
* Furniture
* Office Supplies
